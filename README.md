# Npay-ledger

네이버페이로 쓴 돈을 월별 CSV로 내보냅니다. 쇼핑·현장결제·머니카드·교통카드 지출을 **중복 없이, 총액 기준**으로 모읍니다. 가계부 정리를 위해 만들었습니다.

## 결과 예시

- [examples/2026-08.csv](examples/2026-08.csv)
- [examples/2026-09.csv](examples/2026-09.csv)
- [examples/2026-10.csv](examples/2026-10.csv)
- [examples/summary.csv](examples/summary.csv)

## 무엇을 받나

| 소스 | 내용 |
|---|---|
| 결제내역 (pay.naver.com/pc/history) | 쇼핑 주문, 간편결제, 현장결제, 예약, 콘텐츠 결제 전부 |
| 머니카드 내역 (card.pay.naver.com) | 머니카드 국내·해외 결제와 교통카드 사용 |

머니카드로 낸 결제는 두 곳에 모두 나타나므로 하나로 합칩니다. 포인트·머니로 낸 금액도 지출로 셉니다. 32,000원을 포인트 11,636원과 머니 20,364원으로 냈으면 32,000원 한 행이고, 포인트·머니 컬럼에 나뉘어 적힙니다.

## 설치

Python 3.8 이상.

```
pip install -r requirements.txt
playwright install chromium
```

## 실행

```
python npay_ledger.py                 # 전체 기간
python npay_ledger.py --since 2026-01 # 2026년 1월부터
```

평소에는 `--since`로 최근 달만 받으세요. 전체 기간은 결제 건수만큼 상세 조회가 나가게 됩니다. 

Chromium 창이 열립니다. 네이버에 로그인되어 있지 않으면 그 창에서 직접 로그인하세요. 로그인되면 스크립트가 알아서 이어갑니다. 로그인할 때 **로그인 상태 유지**를 켜 두면 로그인 상태가 `profile/` 디렉터리에 남아 다음 실행부터 로그인 창이 뜨지 않습니다.

| 옵션 | 기본값 | 설명 |
|---|---|---|
| `--since YYYY-MM` | 전체 | 이 달부터만 내보낸다 |
| `--out DIR` | `out` | 출력 디렉터리 |
| `--profile DIR` | `profile` | 브라우저 프로필 디렉터리 |

네트워크 없이 변환 로직만 검사하려면 `python test_npay_ledger.py`를 실행합니다.

## 출력

`out/YYYY-MM.csv`가 한 달치 거래내역, `out/summary.csv`가 월별 요약입니다.

거래내역 컬럼: 일시, 구분(결제/환불), 금액, 가맹점, 상품명, 카드, 계좌, 머니, 포인트, 기타, 소스(쇼핑/머니카드/교통), 유형, 상태, 거래ID, 원거래ID, 원거래일시, 업종코드, 상세URL

요약 컬럼: 월, 건수, 결제액, 환불액, 순지출

## 환불 처리

- 거래내역에는 환불이 **환불된 날짜**에 마이너스 행으로 들어갑니다. `원거래ID`와 `원거래일시`가 원래 결제를 가리킵니다.
- 월별 요약에서는 환불을 **원래 결제한 달**에서 뺍니다. 8월 10일에 27,400원을 내고 8월 19일에 23,300원을 환불받았으면 거래내역에는 두 행이 생기고, 8월 요약의 순지출은 4,100원입니다.
- 환불일은 쇼핑 주문은 주문 상세에서, 머니카드 결제는 머니카드 취소 내역에서, 머니로 낸 결제는 머니 내역에서 가져옵니다. 다른 회사 카드로 낸 결제의 환불일은 네이버페이가 보여 주지 않아 결제일로 대체하고 상태 컬럼에 `환불일 미상(결제일 대체)`라고 적습니다.

## 보안

- 아이디와 비밀번호를 입력받지 않습니다. 로그인은 열린 Chromium 창에서 직접 합니다.
- 로그인 쿠키는 `profile/`에만 저장되고 어디에도 전송되지 않습니다. `profile/`과 `out/`은 `.gitignore`에 들어 있습니다.
- 네이버페이 서버 외에 다른 곳과 통신하지 않습니다.

## 제한

- 네이버페이의 비공개 API를 쓰므로 네이버 쪽 변경으로 언제든 깨질 수 있습니다. 응답이 예상과 다르면 **CSV를 쓰지 않고 중단**합니다. 빈 결과를 정상으로 오해해 지출이 빠지는 일을 막기 위해서입니다.
- 머니 내역은 네이버가 최근 1년치만 주므로, 머니로 낸 결제의 환불일은 1년 안의 것만 찾습니다.
- 머니카드는 한 장만 지원합니다.
- 매 실행마다 전체를 다시 받습니다. 결제 500건 기준 2~3분 걸립니다.
